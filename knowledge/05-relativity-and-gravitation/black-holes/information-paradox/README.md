# Information paradox
> [Relativity and Gravitation](../../README.md) › [Black holes](../README.md) · Literature: [papers.md](papers.md)

**Scope.** Hawking's 1976 argument for non-unitarity, Page curve and Page time, black-hole complementarity, AMPS firewall paradox, ER=EPR, quantum extremal surfaces, entanglement islands and replica wormholes (2019), Hayden–Preskill decoding, soft hair, status in non-AdS settings.

**Core ideas.**
- If radiation is exactly thermal, a pure state evolves into a mixed state — violating unitarity.
- Unitarity requires the radiation entropy to rise then fall (Page curve), turning over at roughly half the evaporation.
- Semiclassical gravity computations including "islands" reproduce the Page curve — but how information gets out in a local, operational sense is still debated.

**Key equations.**
$$S_{\text{rad}}=\min\,\text{ext}_I\left[\frac{\text{Area}(\partial I)}{4G\hbar}+S_{\text{bulk}}(R\cup I)\right]$$
