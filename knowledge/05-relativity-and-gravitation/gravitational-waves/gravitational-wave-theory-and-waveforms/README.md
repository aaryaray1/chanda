# Gravitational-wave theory and waveforms
> [Relativity and Gravitation](../../README.md) › [Gravitational waves](../README.md) · Literature: [papers.md](papers.md)

**Scope.** Linearized Einstein equations in TT gauge, plus and cross polarizations, energy flux (Isaacson), quadrupole formula and Peters–Mathews inspiral, chirp mass, post-Newtonian expansion, effective-one-body and IMRPhenom models, numerical-relativity surrogates, black-hole perturbation theory and quasinormal modes, memory effect, tidal deformability.

**Core ideas.**
- GWs are generated by time-varying mass quadrupoles; there is no dipole radiation (momentum conservation).
- Frequency sweeps upward ("chirp") as orbits shrink; the chirp rate measures $\mathcal M$.
- Waveform accuracy limits parameter estimation and GR tests as detectors improve.

**Key equations.**
$$\dot f=\frac{96}{5}\pi^{8/3}\left(\frac{G\mathcal M}{c^3}\right)^{5/3}f^{11/3},\qquad \ddot h_{ij}=\Box h_{ij}=0\ (\text{vacuum, TT gauge})$$
